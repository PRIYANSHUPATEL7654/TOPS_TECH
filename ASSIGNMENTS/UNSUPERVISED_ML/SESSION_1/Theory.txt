2. Create a table comparing supervised and unsupervised learning in at least four points using real-world app examples.

-------------------------------------------------------------------------------------------------------------------------------
| Feature            | Supervised Learning                                    | Unsupervised Learning                         |
| ------------------ | ------------------------------------------------------ | --------------------------------------------- |
| Training Data      | Uses labeled data                                      | Uses unlabeled data                           |
| Objective          | Predict known outputs                                  | Discover hidden patterns                      |
| Example App        | Instagram feed ranking predicts posts a user will like | Spotify groups similar songs into playlists   |
| Algorithms         | Linear Regression, Decision Trees, Random Forest, SVM  | K-Means, DBSCAN, Hierarchical Clustering, PCA |
| Output             | Predicted class/value                                  | Clusters or groups                            |
| Real-world Example | Gmail spam detection                                   | Netflix customer segmentation                 |
-------------------------------------------------------------------------------------------------------------------------------

Supervised learning learns from historical labeled examples, while unsupervised learning analyzes unlabeled data to discover similarities, clusters, or hidden structures.

5. Find a real-world dataset suitable for customer segmentation.

One of the most commonly used datasets is the Mall Customer Segmentation Dataset.

Dataset Link:
https://www.kaggle.com/datasets/vjchoudhary7/customer-segmentation-tutorial

Dataset Structure : 

-------------------------------------------------------------------------
| Feature                | Description                                  |
| ---------------------- | -------------------------------------------- |
| CustomerID             | Unique customer identifier                   |
| Gender                 | Male or Female                               |
| Age                    | Customer age                                 |
| Annual Income (k$)     | Annual income in thousand dollars            |
| Spending Score (1–100) | Spending behavior score assigned by the mall |
-------------------------------------------------------------------------

Number of Features
- 5 columns
- 200 customer records

Datatypes : 

--------------------------------
| Feature        | Type        |
| -------------- | ----------- |
| CustomerID     | Integer     |
| Gender         | Categorical |
| Age            | Numerical   |
| Annual Income  | Numerical   |
| Spending Score | Numerical   |
--------------------------------

Is the Dataset Labeled?
-> No. It is an unlabeled dataset, making it suitable for unsupervised learning techniques such as K-Means, Hierarchical Clustering, and DBSCAN.

Why This Dataset?
-> This dataset contains customer demographic and spending information without predefined labels. Clustering algorithms can identify different customer segments, helping businesses design targeted marketing campaigns and improve customer engagement.
