=====================================
HOW TO GET GEMINI API KEY
=====================================

1. Go to:
https://aistudio.google.com/app/apikey

2. Create API Key

3. Open backend/main.py

4. Replace:
YOUR_GEMINI_API_KEY

with your actual API key

=====================================
HOW TO RUN BACKEND
=====================================

cd backend

pip install -r requirements.txt

uvicorn main:app --reload

Backend:
http://127.0.0.1:8000

=====================================
HOW TO RUN FRONTEND
=====================================

Open frontend/index.html in browser
