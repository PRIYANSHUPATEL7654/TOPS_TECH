5. Imagine you are building a 'similar movies' feature for a movie app. Briefly describe which linkage method (single, complete, average, or Ward) you would choose for grouping movies by user ratings and why.

----------------------------------------------------------------------------------------------------------------------------------------------
| Linkage Method   | Description                                  | Advantages                                | Disadvantages                |
| ---------------- | -------------------------------------------- | ----------------------------------------- | ---------------------------- |
| Single Linkage   | Uses the minimum distance between clusters   | Can detect irregular cluster shapes       | Suffers from chaining effect |
| Complete Linkage | Uses the maximum distance between clusters   | Produces compact clusters                 | Sensitive to outliers        |
| Average Linkage  | Uses the average distance between all points | Balanced clustering                       | Computationally slower       |
| Ward Linkage     | Minimizes within-cluster variance            | Produces compact, well-separated clusters | Assumes spherical clusters   |
----------------------------------------------------------------------------------------------------------------------------------------------

Best Choice
Ward Linkage

Ward linkage is the most suitable choice for building a Similar Movies recommendation feature.

Reason

Movie recommendation systems generally group movies based on similarities in user ratings, genres, watch history, popularity, and viewing behavior.

Ward linkage:

Minimizes the variance within each cluster.
Produces compact and homogeneous groups.
Keeps similar movies together while separating different movie categories.
Reduces the chances of placing unrelated movies in the same cluster.

For example:

Cluster 1
----------
Avengers
Iron Man
Captain America
Thor

Cluster 2
----------
The Conjuring
Insidious
Annabelle

Cluster 3
----------
Toy Story
Frozen
Moana

Each cluster contains movies with similar characteristics, making recommendations more accurate.

Why Not the Others?
Single Linkage
Creates long chain-like clusters.
May group unrelated movies because of one similar rating.

Example:

Movie A
↓

Movie B
↓

Movie C
↓

Movie D

Even though Movie A and Movie D are very different, they may end up in the same cluster.

Complete Linkage
Produces compact clusters.
Sometimes splits movies that are actually similar because it considers the farthest distance between points.
Average Linkage
Better than Single Linkage.
More balanced clustering.
However, it is not as effective as Ward linkage for recommendation systems.
Final Answer

Ward Linkage is the preferred method for a movie recommendation system because it creates compact and well-separated clusters by minimizing the variance within each cluster. This results in groups of movies that are highly similar in terms of user ratings and viewing behavior, improving the accuracy and relevance of recommendations.

Conclusion

Ward linkage provides the best clustering quality for movie recommendation systems. It creates balanced, homogeneous clusters that help users discover movies similar to those they have already enjoyed.
